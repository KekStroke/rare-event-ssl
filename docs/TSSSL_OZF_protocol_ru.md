# OZF: проверка переносимости эффекта C6 на другой вид и публичные данные (протокол зафиксирован до запуска обучений, 2026-10-20)

## Вопрос
Воспроизводится ли на Overlapping Zebra Finch (OZF, Zenodo 15507508, Mahon et al. 2025) эффект H24/C6: предобучение событийной ветки на синтетических смесях с перекрытиями против смесей без перекрытий (при одинаковом составе вызовов) меняет recall на перекрывающихся реальных вызовах, и два пути предсказания (событийный и покадровый) реагируют противоположно?

## Объём (согласован)
- Только R3 (modern-блок, событийная ветка, без HuBERT-цели): два корпуса предобучения (с перекрытиями / без), по три сида, одинаковый FT и декодер. Шесть обучений предобучения, шесть FT.
- Главная проверка: парные разности на реальном тестовом сплите OZF (13 записей), в том числе на перекрывающихся вызовах, при согласованном FAR.
- Шесть синтетических тестовых наборов OZF Synthetic: дополнительный анализ только инференсом сохранённых FT-моделей.
- Сравнение с Voxaboxen: наш recall@FAR и опубликованный mAP несопоставимы; считаем (а) mAP@0.5/0.8 IoU по коду Voxaboxen на наших предсказаниях того же тестового сплита в реальном масштабе времени, и (б) при наличии времени запуск Voxaboxen на OZF train по его штатному скрипту, чтобы оценить обе системы нашим протоколом. (б) это одно дополнительное обучение, запускается после основных шести.

## Данные и сплит (официальные, не меняются)
- train 46 / val 6 / test 13 записей по 60 с, 44.1 кГц; события 5514 / 1246 / 1744; класс один (VOC).
- Наши роли: FT на train; val = dev для выбора порогов декодера (и только для этого); test не используется ни для чего до финального подсчёта.
- Источники для синтетического предобучения: только train-записи. Вызовы = аннотированные интервалы train-записей (точные границы). Фон = участки train-записей без аннотаций длиной ≥1.0 с (замедленных) с отступом 50 мс от аннотаций. Val и test не участвуют ни в вызовах, ни в фоне.

## Обработка времени
- Замедление в 2 раза приёмом Voxaboxen (make_slowed_version.py): отсчёты сохраняются, объявленная частота делится на 2, затем ресемплинг в 16 кГц; времена аннотаций умножаются на 2. Медиана вызова 106 мс → 212 мс замедленных ≈ 10 токенов по 20 мс; минимум длительности декодера 0.15 с замедленных = 75 мс реальных (5-й перцентиль длительностей).
- Все внутренние величины в замедлённых секундах; для mAP и для сравнения с Voxaboxen времена делятся на 2 обратно.

## Синтетическая конструкция (парный контроль)
- Смесь 5 с (замедленных) = кроссфейд фоновых сегментов + n вызовов, n ~ U{1..10} (реальная плотность OZF 2.2 вызова/с → ≈5.5 на 5 с замедленных).
- Парный режим `TSSSL_PAIRED=1` для обоих плеч: по индексу смеси рисуются n, идентификаторы вызовов и усиления; затем список обрезается до наибольшего префикса, который помещается последовательно с зазором ≥0.1 с; этот же обрезанный список используется в обоих плечах. Плечо «без перекрытий»: последовательная расстановка с зазором ≥0.1 с на случайных свободных позициях; плечо «с перекрытиями»: те же вызовы на равномерно случайных позициях без ограничений. Состав, число, длительности и усиления вызовов идентичны по плечам по построению; различаются только позиции.
- Ожидаемая доля перекрывающихся вызовов в плече с перекрытиями ≈0.3 (у реального OZF 0.32 по нашему определению пересечения интервалов). Измеряется на 1500 смесях до запуска и записывается.

## Модель, обучение, декодер (как в основной статье, кроме перечисленного)
- Modern-блок 8×384 (17.8M), токены 20 мс, событийная ветка (наличие, onset ±1 токен, лог-длительность), 20k шагов, batch 32×5 с, lr 5e-4, сиды 0/1/2.
- FT: 1.5k шагов, batch 8×10 с на 46 train-записях, те же потери; ветка инициализируется из предобучения. FT-модель сохраняется для инференса на синтетических тестах.
- Декодер экземпляров: пики onset, сетка d_min расширена вниз под короткие вызовы: {0.04, 0.06, 0.1, 0.2, 0.3} с замедленных; th_on {0.1..0.8}; min_score {0, 0.1, 0.2, 0.3}; длительность exp(logdur), обрезка [0.15, 5] с. Покадровый декодер тех же моделей как в основной статье. Параметры выбираются на val под бюджет FA и затем заморожены.
- Критерий: строгое сопоставление с tau = 0.1 с замедленных (50 мс реальных, половина медианного вызова), допуск по концу max(tau, 0.5·длительности), class-agnostic. Бюджет ложных тревог: 400 FA на замедленный час (≈10 % от частоты вызовов 3925/замедл. ч). Согласованные точки 200 / 400 / 800 FA/замедл. ч. Подмножество перекрывающихся референсов: пересечение интервалов с другим референсом (FAR глобальный).
- Интервалы: парный бутстрэп по 13 тестовым записям, B = 2000, запись несёт все сиды; разброс сидов отдельно. Точка отчётности отбрасывается, если определена менее чем в 80 % выборок.

## Что считается результатом
- Воспроизведение: разность «без − с» на перекрывающихся при согласованном FAR с интервалом, не содержащим ноль, и покадровый путь без ухудшения или с улучшением → переносимый эффект конструкции обучающих данных.
- Невоспроизведение: граница применимости, фиксируется без новых переборов архитектур.
- Любой исход публикуется.

## Что не делается
Новые архитектуры, другие наборы Zenodo, подбор гиперпараметров под test, изменение сплита.
